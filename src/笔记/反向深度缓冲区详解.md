# Three.js 反向深度缓冲区详解

## 概述

反向深度缓冲区（Reversed Depth Buffer）是一种先进的深度测试技术，通过反转传统的深度值分布来提供更好的深度精度，特别是在处理大范围场景时能有效解决 Z-fighting 问题。

## 核心原理

### 传统深度缓冲区的问题

在传统的深度缓冲区中：

- 深度值范围：[0, 1]，其中 0 表示近平面，1 表示远平面
- 深度精度分布不均匀：近处精度高，远处精度低
- 在大范围场景中容易出现 Z-fighting 现象

### 反向深度缓冲区的优势

反向深度缓冲区将深度值反转：

- 深度值范围：[1, 0]，其中 1 表示近平面，0 表示远平面
- 提供更均匀的深度精度分布
- 显著减少 Z-fighting 问题
- 比对数深度缓冲区更快更准确

### 3. 核心实现机制

#### 深度函数映射表

```javascript
// 反向深度函数映射表 - WebGLState.js
const reversedFuncs = {
  [NeverDepth]: AlwaysDepth, // 从不通过 -> 总是通过
  [LessDepth]: GreaterDepth, // 小于 -> 大于
  [EqualDepth]: NotEqualDepth, // 等于 -> 不等于
  [LessEqualDepth]: GreaterEqualDepth, // 小于等于 -> 大于等于
  [AlwaysDepth]: NeverDepth, // 总是通过 -> 从不通过
  [GreaterDepth]: LessDepth, // 大于 -> 小于
  [NotEqualDepth]: EqualDepth, // 不等于 -> 等于
  [GreaterEqualDepth]: LessEqualDepth, // 大于等于 -> 小于等于
};
```

#### 深度缓冲区管理

```javascript
// DepthBuffer类中的关键方法
setReversed: function (reversed) {
  if (currentReversed !== reversed) {
    const ext = extensions.get("EXT_clip_control");

    if (reversed) {
      // 设置为反向深度：[0,1] 深度范围
      ext.clipControlEXT(ext.LOWER_LEFT_EXT, ext.ZERO_TO_ONE_EXT);
    } else {
      // 设置为标准深度：[-1,1] 深度范围
      ext.clipControlEXT(ext.LOWER_LEFT_EXT, ext.NEGATIVE_ONE_TO_ONE_EXT);
    }

    currentReversed = reversed;

    // 重新设置深度清除值以适应新的深度范围
    const oldDepth = currentDepthClear;
    currentDepthClear = null;
    this.setClear(oldDepth);
  }
}
```

#### 深度测试函数自动转换

```javascript
setFunc: function (depthFunc) {
  // 如果使用反向深度缓冲区，需要反转深度函数
  if (currentReversed) {
    depthFunc = reversedFuncs[depthFunc];
  }

  // 设置WebGL深度函数
  if (currentDepthFunc !== depthFunc) {
    switch (depthFunc) {
      case LessDepth:
        gl.depthFunc(gl.LESS);
        break;
      // ... 其他深度函数
    }
    currentDepthFunc = depthFunc;
  }
}
```

#### 深度清除值处理

```javascript
setClear: function (depth) {
  if (currentDepthClear !== depth) {
    // 如果使用反向深度缓冲区，需要反转深度值
    if (currentReversed) {
      depth = 1 - depth;
    }

    gl.clearDepth(depth);
    currentDepthClear = depth;
  }
}
```

## 技术深入分析

### 1. 深度精度数学原理

#### 传统深度缓冲区精度分布

```
传统深度分布（非线性）：
- 近平面(z=near): depth = 0
- 远平面(z=far):  depth = 1
- 中间值: depth = (far/(far-near)) * (1 - near/z)

精度问题：
- 90%的精度集中在前10%的距离范围内
- 远距离物体精度严重不足
```

#### 反向深度缓冲区精度分布

```
反向深度分布：
- 近平面(z=near): depth = 1
- 远平面(z=far):  depth = 0
- 中间值: depth = near/z

精度优势：
- 精度分布更加均匀
- 远距离物体获得更好的深度精度
- 有效减少Z-fighting现象
```

### 示例说明

这个示例创建了三个并排的渲染器来对比不同深度缓冲区技术的效果：

1. **标准深度缓冲区**：展示传统深度测试的 Z-fighting 问题
2. **对数深度缓冲区**：使用对数分布改善深度精度，但性能较慢
